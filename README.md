# WanderWise – Smart Travel Guide

## About the Project

WanderWise is a web-based travel guide designed to help users explore destinations and plan short trips more easily. The website provides travel recommendations, practical travel tips, a media gallery, and a contact form through a simple and interactive user interface.

The project was developed using HTML, CSS, and JavaScript, with a focus on usability, organized content, and interactive features.

## Project Objectives

- Help users discover travel destinations.
- Provide practical advice for planning short trips.
- Present destination information in an organized format.
- Display travel-related images and video content.
- Allow users to contact the team through an interactive form.
- Present team members through a dynamic webpage.

## Features

### 1. Home Page
**File:** `index.html`

Introduces the WanderWise website, its purpose, and the main services available to visitors.

### 2. Destinations Page
**File:** `destinations.html`

Displays recommended travel destinations through destination cards and a comparison table to help users explore available options.

### 3. Travel Tips Page
**File:** `tips.html`

Provides organized travel tips and practical recommendations to help users prepare for their trips.

### 4. Media Gallery
**File:** `gallery.html`

Showcases travel-related images and includes an interactive video player that uses an external video link.

### 5. Contact Page
**File:** `contact.html`

Contains a contact form with input validation and feedback messages to help users submit their information correctly.

### 6. Team Members Page
**File:** `members.html`

Displays the project team members and includes a JavaScript feature that randomly rearranges their names.

## Technologies Used

- **HTML5:** Structures the website pages and content.
- **CSS3:** Controls the website layout, colors, styling, and visual presentation.
- **JavaScript:** Implements interactive features, form validation, random name shuffling, and date updates.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the navigation menu to explore the different pages.

The website can be opened locally in a browser without a backend server for its basic functionality.
